# SentinelCore – Enterprise Security Operations Platform

## Overview

SentinelCore is an enterprise security operations platform designed
to provide infrastructure monitoring, security management,
vulnerability management, and audit and compliance capabilities.

## Objectives

- Infrastructure monitoring
- Security management
- Vulnerability and risk assessment
- Audit and compliance
- Alert management
- Authentication and authorization

## Technology Stack

### Backend
- Java 21
- Spring Boot 4.x
- Maven
- Spring Data JPA
- Spring Security
- Lombok

### Database
- PostgreSQL

### Frontend
- React 19
- Vite
- Axios

### Development Tools
- IntelliJ IDEA
- Visual Studio Code
- Postman
- Git/GitHub

### Deployment
- Docker
- Kubernetes
- AWS

## Project Architecture

The application follows a layered architecture with
domain, event, data, security, and infrastructure concerns.
